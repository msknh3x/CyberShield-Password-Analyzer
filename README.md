

# 🛡️ CyberShield — Password Strength Analyzer V2

A modern, real-time **Cybersecurity Utility & Password Strength Analyzer** built with **Vanilla JavaScript, HTML5, and CSS3**. CyberShield calculates password complexity, estimates cryptographic entropy, assesses risk levels, and checks for commonly breached passwords in real-time with a sleek dark-themed cybersecurity interface.

- 🌐 **Live Interactive Tool:** https://msknh3x.github.io/CyberShield-Password-Analyzer/

##  Key Features

- ⚡ **Real-Time Input Evaluation:** Instant feedback on password strength as you type using event-driven JavaScript.
- 📋 **Multi-Factor Rule Verification:**
  -  **Length:** Checks for 8+ characters.
  -  **Uppercase:** Verifies uppercase alphabetical characters (`A-Z`).
  -  **Numbers:** Validates numerical digits (`0-9`).
  -  **Special Symbols:** Detects symbols and punctuation (`!@#$%^&*...`).
- 📊 **Dual Visual Metrics:**
  - **Animated Progress Bar:** Smooth width and color-coded transitions based on score.
  - **Dynamic Circular Score Ring:** Displays percentage score (0% – 100%) with adaptive border colors.
- 🧠 **Security Statistics & Risk Assessment:**
  - **Entropy Estimation Score:** Calculates entropy metric based on length and character variance.
  - **Live Character Counter:** Displays exact string length.
  - **Dynamic Risk Level:** Categorizes vulnerability into *High*, *Medium*, *Low*, or *Very Low*.
- 🚨 **Breach Database Check:** Scans input against a dictionary of commonly breached/weak passwords.
- 👁️ **Show / Hide Password Toggle:** Easily toggle between masked and plain text input.
- 🎨 **Modern Cyber-Tech UI:** Glassmorphism (`backdrop-filter`), neon security color schemes, and responsive grid layouts.
